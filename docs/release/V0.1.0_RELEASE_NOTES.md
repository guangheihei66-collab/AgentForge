# AgentForge v0.1.0

AgentForge v0.1.0 is the first stable release of the governed AI Agent Runtime.

## Core Runtime

AgentForge provides a governed execution path:

User Goal → Planner → Plan Validation → Capability Resolver → Human Approval → Approval Snapshot → Project Authority → AgentRuntime → ToolGateway → Execution → Observation → Controlled Replan → Evidence / Audit → Report

## Governance and Security

- Deterministic capability resolution and a Human Approval hard gate.
- Approval Snapshot and Project workspace-authority binding.
- ToolGateway as the final execution boundary with workspace containment.
- Fresh Approval required for successor Plans; old Approvals cannot authorize successors.
- Distinct SUCCESS, FAILED, and REJECTED execution semantics.
- Runtime/test database isolation, credential redaction, and no chain-of-thought persistence.

## Operability

- Runtime diagnostics with deterministic health states.
- Version and Git revision identity.
- Launcher startup diagnostics.
- Redacted Provider diagnostics and a frontend Diagnostics view.
- Bounded ToolExecution diagnostic aggregation.

## Provider

The verified release configuration uses an OpenAI-compatible provider with DeepSeek V4 Flash and `json_object` structured output. Credentials remain outside the repository.

## Known Non-Blocking Issue

Legacy synthetic null-Project Approvals are not visible through the normal pending-Approval listing. They remain visible through Task detail and can be rejected through the supported Approval lifecycle API. Severity: P3; stable blocker: No.

## Scope

v0.1.0 does not include an installer, automatic updater, cloud deployment, arbitrary shell execution, expanded autonomous permissions, or an automatic release pipeline.
