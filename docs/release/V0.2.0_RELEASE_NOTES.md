# AgentForge v0.2.0

AgentForge v0.2.0 is the portfolio release of the governed Agent Runtime and evidence-grounded release analysis workflow.

## Highlights

- Repository Analyst Agent with a governed Agent Runtime.
- Real OpenAI-compatible / DeepSeek Planner and Analyst providers using bounded `json_object` structured output.
- Evidence-grounded Analyst Reports with release-readiness recommendations and evidence sufficiency validation.
- Human Approval, Approval Snapshot, CapabilityResolver, Project Authority, ToolGateway, workspace containment, and Controlled Replan with fresh successor approval.
- Durable Evidence, Audit, Diagnostics, command provenance, and no chain-of-thought persistence or display.
- Native `en-US` / `zh-CN` console localization with locale persistence.
- Secure Windows Provider configuration with user-scoped DPAPI API-key storage.
- One-click, single-instance Windows Launcher with tray behavior and no terminal window.
- Deterministic, isolated unit and smoke profiles plus explicit failed-Replan finalization.

## Limitations

This is a self-hosted portfolio release, not a security certification. It does not provide multi-agent orchestration, RAG, MCP, local models, arbitrary shell autonomy, autonomous code modification, browser automation, SSO/LDAP/MFA, Kubernetes, Docker deployment, or an installer/updater. The available tools remain allowlisted read-safe Git/File operations and predefined test profiles. Production deployment should add a managed database, operational job durability, and independently reviewed enterprise security controls.
