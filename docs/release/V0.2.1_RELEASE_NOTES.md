# AgentForge v0.2.1

AgentForge v0.2.1 is a bounded maintenance release for historical task-state reconciliation.

- Adds a supported, auditable operation for Tasks stranded in `RUNNING` by old Runtime/Replan validation failures.
- Reconciles only persisted, proven failures and performs zero re-execution.
- Fails closed when execution, approval, successor-plan, or terminal-failure evidence is ambiguous.
- Preserves Plans, Approvals, ToolExecutions, Evidence, reports, and existing Audit history.
- Does not classify Tasks by age and does not automatically fail ambiguous stale Tasks.

The existing `cf1d0eb` regression continues to prevent new failed replans from remaining `RUNNING`.
