# AgentForge Roadmap

## Phase 1: Backend foundation

Define application contracts, configuration, storage repositories, and API boundaries.

## Phase 2: Workflow engine

Implement the Task state machine, plan validation, transitions, cancellation, and failure handling.

## Phase 3: Tool Gateway

Add the allowlisted Git, File, and predefined Test tools with permission and workspace checks.

## Phase 4: Approval and Audit

Add plan approvals, rejection/cancellation, evidence records, audit events, and bounded execution output.

## Phase 5: Frontend

Add Dashboard, Task Detail, Approval Center, and Report pages.

## Phase 6: Evaluation

Add deterministic workflow/security cases, evidence checks, metrics, and the portfolio demonstration.
